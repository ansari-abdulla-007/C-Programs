# 💻 C Programming: Basics to Advanced

Welcome to the **C-Programs** repository! This repository contains a well-structured collection of C language programs ranging from fundamental syntax and logic building to advanced memory management and file handling concepts.

---

## 📂 Topics Covered

| Level | Topics Included |
| :--- | :--- |
| **🟢 1. Basics & Control Flow** | Data Types, Input/Output, Operators, `if-else`, `switch-case`, Loops (`for`, `while`, `do-while`), Number & Star Patterns |
| **🟡 2. Functions & Arrays** | User-defined Functions, Recursion, 1D & 2D Arrays (Matrix Operations), String Manipulation |
| **🟠 3. Pointers & Structures** | Pointer Arithmetic, Call by Reference, `struct`, `union`, Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`) |
| **🔴 4. Advanced C** | File Handling (`fopen`, `fread`, `fwrite`), Command Line Arguments, Preprocessor Directives, Basic Data Structures |
